# EVO V2 migration boundaries — Draft 1

Development only; no publication or scientific-content approval.

## Source ownership
EVO V2 is the sole future owner of canonical evolutionary concepts, relationships, evidence, timeline events and Paulinella. MBA Hub consumes only approved versioned entrypoints. The legacy Timeline and Master Map remain unchanged source material.

## Migration order
1. Inventory legacy concepts, transitions, visuals and timeline events; retain permanent IDs and provenance.
2. Separate scientifically evidenced edges from selected-pathway and navigation links; do not infer ancestry from a UI arrow.
3. Import records through validated adapters without changing original identifiers or endpoints.
4. Render Timeline and Master Map as independent views over shared EVO records.
5. Add Paulinella as an EVO-only educational feature; require citation review before approval.

## Required validation
Unique stable IDs; resolvable references; explicit relationship kind; evidence/approval states; safe text rendering; cross-view consistency; no MBA scientific-data copies; offline bundle isolation; device and accessibility checks. Reject unreviewed relationships from canonical scientific graphs.

## Release gates
Dedicated EVO repository, reviewed science, complete migration, passing CI, offline testing, device acceptance and publication authorization.
